# AutoPulse Check — Future Ideas (Non-Authoritative)

Everything in this file is brainstorming until promoted through Design -> Plan -> Build -> Test.

Potential future directions:
- guided photo capture with vehicle-zone overlays;
- tire/tread/manual pressure inspection workflow;
- TPMS bridge evidence when compatible hardware exists;
- battery cranking/startup characterization;
- service-specific Check templates for workshop use;
- fleet batch inspection workflows;
- pre-purchase seller/buyer shared report package;
- technician annotations over telemetry timelines;
- evidence comparison against prior evaluations of the same vehicle;
- repair-before/repair-after linked evaluations;
- exportable signed PDF/report package;
- optional cloud synchronization of immutable report artifacts;
- multi-module diagnostics beyond standard powertrain OBD when transport/capability evidence exists;
- VIN-derived configuration hints only when source/provenance is explicit;
- AI-assisted report wording constrained to existing evidence and reviewed findings.

Ideas explicitly outside the current authority:
- autonomous mechanical diagnosis;
- claiming a full inspection from OBD alone;
- DTC clearing as part of Check MVP;
- actuator tests/coding/programming without a separate safety design;
- declaring an unevaluated system healthy.
